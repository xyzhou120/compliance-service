# 本地调试前端重构实施计划

目的：将单文件 debug.html 拆分为轻量前端工程，保留受理、执行、历史结果与配置语义；FastAPI 同源托管。

1. 在既有回归测试基础上增加任务摘要、报告、附件、原文和诊断按需接口的行为测试，校验分页与归属边界；接口层已落地在 `debug_views.py`。
2. 建立 Vue 3/TypeScript/Vite 独立工程和按需路由，任务列表作为默认入口。
3. 配置逐层选择检查项、清单和编辑字段；提交使用已有配置版本冲突校验。
4. 精简 JSON 触发页，受理后进入任务详情；既有附件批量调试入口保留在旧页以兼容迁移。
5. 任务详情分摘要、报告、过程、附件、证据；过程增量分页读取，完整诊断需主动打开，终态停止轮询；候选、缺口和历史问题按页查看。
6. FastAPI 将 /debug 指向前端构建产物，保留 /debug/legacy；分发包包含 web 资源，启动脚本已能在源码变化时构建。
7. 执行后端回归、前端类型检查、生产构建、接口分页验证及桌面/窄屏浏览器流程检查，记录产物大小和已知限制。

拆分职责：前端路由与视图、后端查询投影、静态托管/构建。复用已有规则和账本，避免创建新的执行队列或结果编辑入口。
