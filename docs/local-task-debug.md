# 本地模拟任务与证据查看

本地调试直接在页面输入上游任务参数，自动运行本次检查并展示结果。此入口固定 `callbackMode=none`，不创建结果投递，不要求回调地址可用。

## 启动与使用

在服务目录执行：

```powershell
.\scripts\start-local-debug.ps1
```

打开 `http://127.0.0.1:8091/debug`，填写 mineId、checkCycle、status=running 和检查项，选择取数方式并点击“接收任务并在本地执行”。启动脚本会同时启动 API 和本地调试 Worker，不需要另开终端；Worker 只领取本地调试任务。页面自动刷新，停止刷新不会取消后台执行。

可以展开“任务报文 JSON”，粘贴上游请求填入参数。resultCallbackUrl 仅用于保留模拟报文形状，不发送网络请求。需要重新验证时再次提交会创建新的本地调试任务，历史快照与结果保留。

## 两种取数方式

页面“检查项与清单配置”展示当前支持的检查项、每项涉及资料的清单 ID 和周期。可直接编辑并保存，新的本地任务使用保存后的版本。周期查询规则、正式 code 更改方式和环境配置见 [检查项与清单配置](inspection-catalog-config.md)。

默认选择已有本地 manifest，路径必须是绝对路径。来源系统和 local/test 环境默认从 manifest 读取，矿井必须匹配；范围和证据不能借用其他矿井的数据。原有上传附件、本地文件路径和手工 manifest 功能仍在“直接添加附件或查询已有运行”中。

需要查询 OceanBase 时，复制 `config/local-debug.example.toml` 为部署专用配置，填入授权矿井与附件域名；数据库凭据通过配置指定的环境变量提供。然后执行：

```powershell
.\scripts\start-local-debug.ps1 -Config config/local-debug.toml
```

启动脚本发现 `config/local-debug.toml` 时会自动加载，因此本机配置完成后仍可使用不带参数的启动命令。数据库变量可由进程环境提供，或从被 Git 忽略的 `.local/local-debug.env.json` 读取；文件格式为字符串键值对象，仅允许 `COMPLIANCE_OB_HOST/PORT/DATABASE/USER/PASSWORD`。进程中已有变量优先，脚本退出后恢复本次设置的变量。不要把凭据放入前端或提交到版本库。

2026-10-26 本机已实测 OceanBase 连接和 `610401015959` 的 2026-10 清单查询：156 行去重为 98 个附件，覆盖 8 类资料（本轮未返回生产组织通知单）。实际表的地址字段包含对象键和 bucket，通过 `[attachments].base_url` 拼接 `local_bucket_name/local_attachment_address`，中文、空格、井号和百分号按对象键编码。完整 URL 字段仍受支持。

本机根地址为 `https://172.26.10.67:8082/`。服务使用自签名证书，本地配置通过 `tls_certificate_sha256` 精确绑定该 HTTPS origin 的证书指纹；已与此前下载脚本记录核对一致。其他目标继续使用默认 TLS 校验，证书变化会拒绝请求，不全局关闭校验。已成功下载一份 5,627,493 字节的真实防冲设计 PDF 并核对魔数及 SHA256。配置可用标记只表示适配器已加载，不代表全部附件或业务准确性验收；本轮没有自动发起 98 份资料的完整模型检查。

调试脚本现在同时管理 API 和 `worker --debug-only`。API 端只受理任务，Worker 根据 SQLite 租约领取本地调试任务；关闭页面不会取消任务，关闭启动脚本会停止两个进程。真实长任务的进度摘要显示当前文件、附件冻结数、文件处理数和页面识别数。大批量模型任务的解析中间结果按文件落盘，避免把全部候选长期留在内存；出现技术失败时页面显示错误类型、阶段、文件和页码。

此模式仍只监听回环地址，不需要任务令牌、callback 配置或回调密钥。页面在配置就绪时可选择 OceanBase；实际 DDL、MySQL 兼容驱动和只读权限须按真实环境核对。未配置时不会猜测或尝试连接数据库。

## 结果与溯源

页面上方提供“任务执行记录”：按提交时间倒序显示矿井、周期、执行状态、各检查项结果和已结束项数。支持按矿井/周期筛选、分页及手动刷新；页面可见时每 10 秒刷新一次，新提交或执行结束后立即更新。记录保存在 SQLite 账本中，刷新页面或重启服务后仍可查看。

点击记录会加载该任务各检查项的结果、文件和证据，不重新执行检查、不触发回调。旧版没有任务分组的本地运行仍按单项记录显示。列表仅提供 local/test、none/mock 交付模式的本地执行摘要，生产配置下不可访问。

每个检查项独立展示状态、摘要、规则覆盖与缺口，并可展开：

- 本次检查涉及文件：原始名称、资料类别、状态、文件 ID 和 SHA256；下载失败附件也保留在范围列表中。
- 证据溯源：检查命题或事实对应的文件、页/行/单元格定位和原文。
- 原文证据：尚未形成完整事件链时，也可以查看已解析原文与定位。
- 日报候选、逐日问题、连续事件、进度和完整 JSON。

没有证据不会补造结论，候选不等同确定违规。所有页面字段转义后展示，避免原文内容变成页面代码。
