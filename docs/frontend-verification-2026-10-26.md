# 本地调试工作台重构与验证

已建立独立 Vue 3 + TypeScript + Vite 前端，构建输出到 `compliance_service/web/`，FastAPI 在 `/debug` 与 `/debug/` 托管页面与 `/debug/assets` 资源。原单文件调试器保留在 `/debug/legacy`，供原有附件上传流程使用。

## 信息层级

- 检查项配置：检查项摘要列表 → 选定检查项的清单列表 → 一份清单的编辑表单。保留 code、名称、启停、业务处理器、清单 ID、资料类别、周期和角色保存能力；保存仍校验配置版本。
- 任务记录：分页展示触发时间、矿井/周期、检查项、执行进度、各项结果和执行耗时。点击后进入独立任务详情，使用同一份持久化历史。
- 手动触发：JSON 输入、本地 manifest 路径或已配置 OceanBase 取数、提交动作。受理后跳转本轮任务详情。
- 任务详情：结果与问题、执行链路、涉及附件、证据溯源。问题可直接按证据引用筛选原文，文件可直接查看自身证据。识别候选明确标识，候选不变成确证问题。

## 性能与边界

首屏按需载入任务列表路由，只请求任务摘要，不请求文档快照。任务详情首屏取摘要与报告，打开附件或证据区域才请求数据；附件/证据每页 20 条、链路每页 100 条、缺口每页 20 条。后端 `debug_views.py` 使用 SQLite JSON1 查询需要的字段，避免将大型快照整体解码与传输。

活动任务详情每 3 秒刷新，终态停止；列表仅在存在活动任务时刷新。切换页面取消请求；选中不同检查项时校验请求版本，避免先前响应覆盖当前视图。完整链路通过前后分页保留，不再只保留最后 100 条日志。

构建体积：主 JS 99.14 KB（gzip 38.99 KB），共享 CSS 16.23 KB（gzip 4.38 KB），四个页面路由独立拆包约 3.9–18.7 KB。未引入大型组件库。Node 依赖仅用于开发和构建；已有构建产物且源码未变更时，日常运行不需要启动 Node 服务。

新接口仅面向 local/test、none/mock 交付记录；生产配置下调试页面和接口关闭。已有执行规则、配置版本、结果快照和回调逻辑继续由现有服务负责，前端没有人工改判入口。

## 验证

已执行 Vue 类型检查与 Vite 生产构建、Python 编译检查、379 项后端回归（121.627 秒）和 PowerShell 脚本语法检查。后端新增测试覆盖静态托管、生产隔离、任务聚合、1500 条证据的分页与小响应、失败附件保留、候选原文溯源及历史耗时稳定性。

浏览器实测通过：三个路由导航、配置三级展开、JSON 提交合成卸压反例自动跳转详情并显示 `no_pass`、4 条原文证据筛选、真实历史窗口报告。网络记录确认进入任务详情前未取附件/证据；390px 窄屏 `scrollWidth=390`，没有页面横向溢出。

impeccable 指令和 craft-floor 已用于布局、层级、状态、阅读尺度和响应式设计。其 context 辅助程序下载失败，未执行自动检测器；视觉与流程验证使用实际浏览器和本地截图。此验证不是真实矿井准确率或 OceanBase 正式联调验收。

## 启动

```powershell
.\scripts\start-local-debug.ps1
```

脚本会检查前端构建是否存在或过期，必要时在 `frontend` 执行依赖安装与构建，然后启动 FastAPI。日常地址为 `http://127.0.0.1:8091/debug`。开发前端单独运行方式见 `frontend/README.md`。

候选证据引用已支持按 candidate ID 查看原文片段，并在详情中标记“识别候选”；默认证据列表仍只展示已登记证据。
