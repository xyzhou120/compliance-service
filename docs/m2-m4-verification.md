# 真实文件与两项规则开发验证记录

2026-10-23，本轮开发版本0.2。按用户要求不启动 API 或常驻 worker，只执行离线代码测试、文件读取和安装包单次命令。无人工改判、审批工作台或结果修订状态。

## 本轮交付

- `parsers.py`：原生 PDF 页定位、DOCX 正文/表格、XLSX 工作表/行/单元格，原始字节哈希与逐单元覆盖；扫描、图片、修订、未计算公式和坏文件显式留缺口。
- `sources.py`：明确本地清单、时间范围、文件角色、不可变原件副本与内容缓存。每轮重新绑定矿井/运行/快照证据；缓存校验实现/依赖版本和完整产物摘要；Windows 深路径兼容。
- `fact_extraction.py`：中文表头别名、表格及显式字段记录，提取事件、实际动作、指标、阈值和必要指标全集；普通自然文本保留候选，不猜字段，不混用规范、设计、自述与实际记录。
- `rules.py`：停工撤人与卸压、解危效果检验两项确定性判断，按事件/工作面隔离、批准阈值与有效期、精确数值/单位比较和证据时序输出结果。
- `evaluation.py`：固定预期的离线案例评测，独立记录标签准确率、业务判断分母、可判定率、错误通过数、漏判数、混淆矩阵及证据追溯。
- `service.py`：真实文件模式和原模拟模式共用持久流程，真实文件处理自动续租，不改变历史结果。CLI 增加单次 `check-files` 和 `evaluate-files`；它们不启动监听服务。

依赖仅声明本机已存在的 pypdf、python-docx、openpyxl 和测试 Pillow，未安装新包，未复制 document-parser 代码。

## 法规依据与判定范围

依据本地已保存的《防治煤矿冲击地压细则》矿安〔2026〕82号（2026-09-23施行）、《煤矿重大事故隐患判定标准》第21号令（2026-07-01施行），并交叉核对规则审查修订工作簿。

普通监测触发严格大于阈值；钻屑法钻粉率指数达到临界指标含等于；效果检验解除必须严格小于。检验等于阈值后实际复工可按细则形成不符合证据，不能将重大隐患标准的“超过”偷换成“大于等于”。本轮输出具体细则问题和证据，不自动作最终重大隐患定性。

立即处置没有臆造的分钟阈值。同日/同刻无法证明先后时保留缺口；不把检验完成时刻之前的测值武断判为违法，关联时序不明为 pending。法定现场技术负责人确认从原件取证，不是人工在服务内修改结果。

当前细则规则按事件日期适用；2026-09-23之前材料需要历史规则，首版保守保留缺口。批准要求和阈值暂须明确绑定同一事件与工作面，尚未推断跨事件适用范围。未记载指标全集有效期时仅在显式事件绑定下解释，结果 limitations 公开适用边界，不保证跨期效力。

## 独立复评与修复

独立审查复现并修复：同刻记录误作完整时序、检验与测量关联未闭合、其他目标或未来的否定记录错误影响先前复工、未来指标全集错误适用、观察日期边界不一致，以及缓存产物损坏未重新解析。

再次独立复验确认原问题闭环，截断缓存、保留字节哈希但清空文本块及修改解析版本均触发重新解析。真实源角色与引文角色不一致不得完成。全套测试还覆盖长文件处理续租、无 socket 外发及 Windows 深目录存储。

- **10组固定预期的 DOCX/XLSX/图片文档案例全部符合预期**，涵盖正常两项、等于/超过阈值后复工、缺调度、缺原始指标、同刻时序、资料不全、未来全集和无 OCR 图片。全部标记 synthetic_document；错误通过数0，证据引用均可追溯。这是开发案例结果，不是生产准确率。

## 后续仍需验证
