## 一、真实新布局（建议注册为变体）

### 1. 危险状态矩阵（出现于 prevention_daily / analysis / design / dispatch_daily）

- 表头：危险状态 | 掘进工作面 | 回采工作面
- 单元格：公式/条件文本，例如 1、E_p …；5×10^4
- 候选读法：formula_table（公式条件读法），按组放开
- 预计产出：每条（危险状态，工作面类型）一条条件证据（带单元格定位，formula=true，不产生数值）
- 变体形态：Variant("danger_state_formula", "<group>", ("危险状态","掘进工作面","回采工作面"), "formula_table")
- 需要你确认：
  1) 危险状态的取值（a/b/c 或 弱/中/强）是否等价于危险等级？若是，我把它接到"按等级取阈值"链上；
  2) 掘进/回采两列的公式是否需要算出数值？（默认不算，只作条件证据）

### 2. 调度台账（序号 / 采掘类别 / 盘区名称 / 工作面名称 / 班次 / 班长 / 出勤人数 / 割煤刀数 / 日计划 / 本月累计 / 问题描述）

- 候选读法：field_columns（列名读法），已补别名 工作面名称 → workface
- 预计产出：workface；若表内出现动作/时间/状态列则一并绑定；其余列作为条件证据保留
- 需要你确认：
  1) 出勤人数是否进入判定？（当前字段档案只有 解危人数/应撤人数/实撤人数，没有通用出勤人数；默认不映射）
  2) 当班割煤刀数 / 日计划割煤 / 本月累计割煤 是否要抽取？若要，需要扩字段档案（约 3 个字段）并给出比较语义

### 3. 胡家河式调度表（队组 / 工作面（作业点）名称 / 班次 / 出勤人数 / 产量（t）/进尺（m）/作业内容 / 备注）

- 候选读法：field_columns；工作面（作业点）名称 → workface，作业内容 → work_content
- 预计产出：workface + work_content（"正常生产"这类可推导 continue_work）
- 需要你确认：产量/进尺/作业内容挤在一列时，是否拆成三个字段？（默认不拆，整列作为 work_content）
